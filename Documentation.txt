# Feature Documentation for Payment Entity

## Purpose of the Feature
The Payment feature is designed to model financial transactions within an application that manages accounts and their respective payment statuses. This feature allows for the creation and management of payment records, including associating payments with specific accounts, tracking payment amounts, and managing payment statuses, thus providing a structured and efficient way to handle financial transactions.

## Description
The `Payment` class is an entity that represents a payment transaction in a relational database. It contains several fields that capture the essential attributes of a payment, such as a unique identifier (`id`), an associated account (`account`), the payment amount (`amount`), and the current status of the payment (`status`). 

The class leverages Java Persistence API (JPA) annotations to define its mapping to a database table, ensuring that it can be easily persisted and retrieved. The use of `@ManyToOne` indicates that multiple payments can be linked to a single account, establishing a relationship between these two entities. 

Additionally, the class includes getter and setter methods to access and modify the properties of a payment instance, as well as a method for updating the payment status, allowing for flexibility in managing payment processes.
